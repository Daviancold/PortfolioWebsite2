## Overview

This project was done as part of an NUS summer module (CP2106 Independent Software Development Project) called Orbital, where you and your partner can design a web/mobile application. Since it was our first time doing software engineering, and our only coding knowledge was in C++,
we opted to use Flutter and Dart for its familiar syntax. The core functionality was to create a CRUD-Based application, with additional nice-to-haves such as serverless functions to push notifications and live chatroom.

## Key Features

- **Live Notifications**: Powered by Firebase Functions, it enables push-based notifications for all users of the application.
- **Location and Image Info Tagging**: Using the respective Flutter libraries, it allowed storage of more special information for our listings
- **Stream-Powered Chatroom**: Firebase SDK provides Streams, which in turn provides live updates to data changes in the database, faciliating chatrooms.

## Technologies Used

- **Flutter**: For its vast and easy to use pub.dev libraries
- **Dart**: For its familar syntax to C++/Java and its ability to compile for Android phones
- **Firebase**: For its simple to use SDK that can be integrated without having to use APIs
- **Mockito**: For simple unit and integration tests

## Challenges and Learnings

Since this project was done with no knowledge about good practices, the entire project was written in a monolithic approach. Additionally, there was no proper git management, with branches often having merge-conflicts that often took a long time to resolve. It was also increasingly difficult to implement
new features towards the end of the project, often running into issues where i had to refactor many code just to add something small. This project was actually what got me thinking "there has to be a better way to code this out with better compartmentalisation", leading to the interest in distributed systems.
We were also exposed to the world of testing, making use of Mockito, creating stubs and automating tests on top of user testing.

## Outcome

This project was a great learning experience and was lots of fun, kickstarting my interest in software engineering. We also achieved the Apollo-11 level (second highest difficulty).
